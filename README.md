# Mi Mundo Musical - Interfaz de Reproducción de Música

Este proyecto es una interfaz web donde puedes gestionar, subir y reproducir tu propia música, visualizar sus metadatos (como artista, álbum y portada) y organizar tus canciones por género musical. La aplicación está diseñada para ser colorida y personalizada según los géneros musicales, con un diseño dinámico para cada uno.

Además, puedes añadir canciones a tu biblioteca, eliminarlas, buscar por artista o título y filtrar las canciones por décadas.

## Características

- **Sube tu música**: Permite subir archivos MP3 y ver su portada, artista, álbum y más.
- **Reproduce música**: Puedes escuchar tus canciones directamente desde la interfaz.
- **Personalización por género**: Cada género musical tiene su propio estilo visual.
- **Elimina canciones**: Puedes quitar canciones que no desees mantener en tu biblioteca.
- **Búsqueda**: Barra de búsqueda para encontrar canciones rápidamente por título o artista.
- **Filtro por décadas**: Filtra tu música según la década en la que fue lanzada.

## Tecnologías Usadas

- **HTML**: Estructura de la interfaz web.
- **CSS**: Estilos y diseño personalizado.
- **JavaScript**: Lógica de interacción y gestión de archivos.
- **IndexedDB**: Para almacenar y gestionar la música de manera local en tu navegador.
- **PWA (Progressive Web App)**: Para permitir el funcionamiento offline y mejorar la experiencia del usuario.
